## 关于便宜Linux VPS 和 RackNerd 的常见问题

### RackNerd 是 KVM 还是 OpenVZ？

全系 KVM 虚拟化，独立内核和资源，Docker、自定义内核参数（比如开 BBR）这些 KVM 该有的能力都正常可用。选购便宜 VPS 时优先确认架构，OpenVZ/LXC 类架构在容器支持和资源隔离上限制多，低价机型里尤其常见。

### 一年十美元的 VPS 能稳定吗？

判断便宜商家靠不靠谱，看几个硬指标就行：RackNerd 从 2019 年前后开始运营，在 LowEndTalk 等主机社区长期活跃，促销套餐常年循环在售——跑路型商家不会持续维护这种产品线。当然，任何低价 VPS 都建议把重要数据做定期备份，这是习惯问题，跟商家无关。

### 1GB 内存到底够不够用？

轻量博客（静态站或带缓存的 WordPress）、学习 Linux、跑一两个小服务，1GB 加 swap 足够。要跑数据库加应用的组合，直接上 2.5GB 或 3GB，别在内存上硬省——差价一年也就十美元。

### 月流量 1.5TB 是什么概念？

1.5TB/月摊下来，相当于平均持续 4.6 Mbps 的流量跑一整个月。个人博客、API 服务、自用工具基本用不到零头；但视频站、下载站这种持续大流量的用途明显不够，要么选更高档套餐，要么换按流量计费的云厂商。

### 系统装错了能重装吗？

可以，SolusVM 面板里自助重装，主流发行版模板随便换，免费且不用发工单。这也是 KVM 机型的基本盘，买之前确认清楚就行。
